## Códigos de los documentos

| Código | Qué es |
|---|---|
| `COT` | Cotización |
| `FAC` | Factura de venta |
| `LM` | Lista de materiales |
| `LOT` | Lote fabricado |
| `OC` | Orden (pedido) de compra |
| `OP` | Orden de producción |
| `OPI` | Orden de servicio técnico |
| `REC` | Recepción de una compra |
| `RT` | Ruta de producción |
| `SOL` | Solicitud que llegó desde el sitio web o el portal |
| `TR` | Traslado entre bodega y sucursal |

## Palabras de la A a la Z

| Palabra | Qué significa |
|---|---|
| **Abono** | Pago de una parte del saldo de una factura de crédito. |
| **Ajuste de inventario** | Corrección de la existencia de un producto en una ubicación, con un motivo (conteo, merma, uso interno…). |
| **Anular** | Dejar sin efecto una venta por un error. La venta no se borra: queda *Anulada* y la mercadería vuelve al inventario. |
| **Auditoría** | Bitácora de solo lectura con todo lo que se hizo en el sistema: quién, qué, cuándo y desde dónde. |
| **BOM** | Siglas en inglés de *lista de materiales*: los componentes que lleva una unidad de un producto fabricado. |
| **Bodega principal** | Ubicación donde se recibe lo comprado, se guarda lo fabricado y se toman los materiales de producción. |
| **Borrador** | Documento en preparación que todavía no tiene efecto (compra, cotización u orden de producción). |
| **Centro de trabajo** | Mesa, máquina o estación del taller donde se hace una operación de la ruta. |
| **Cobertura** | En una orden de servicio, si el trabajo se cobra (*con costo*) o lo cubre una garantía. |
| **Concesión** | Decisión de calidad de aceptar unidades con un defecto documentado; entran al inventario. |
| **Conforme / no conforme** | Unidad que pasó o no pasó la inspección de calidad. |
| **Consulta web** | Solicitud que un cliente envía desde el sitio o el portal. |
| **Contado** | Pago completo en efectivo en el momento de la venta. |
| **Costo promedio** | Costo de cada unidad en existencia, calculado por el sistema con las compras y entradas (incluye flete y gastos). |
| **Cotización** | Propuesta de precios para un cliente; vale 15 días y se convierte en venta. |
| **Crédito** | Venta que el cliente paga después, en un plazo de 1 a 365 días. |
| **CSV** | Tipo de archivo de datos que se abre con Excel. |
| **Cuota fija (régimen)** | Régimen de impuestos en el que la empresa no cobra IVA en sus ventas; el sistema lo indica bajo el subtotal. |
| **CxC** | Cuentas por cobrar: lo que los clientes deben por facturas de crédito. |
| **Dashboard** | Pantalla de inicio con los indicadores y los pendientes del día. |
| **Días de inventario** | Para cuántos días alcanza la existencia al ritmo de uso de los últimos 90 días. |
| **Disponibilidad** | Lo que ve el cliente en el sitio: *Disponible*, *Pocas unidades* o *Bajo pedido*. |
| **En camino** | Unidades de compras ordenadas que todavía no llegan. |
| **Existencia (stock)** | Unidades que hay de un producto, en total o en cada ubicación. |
| **Garantía del producto** | Plazo, desde la venta, en que NORCOR atiende fallas de un producto sin costo. Se define en la ficha del producto. |
| **Garantía del trabajo** | Plazo, desde que se completa una orden de servicio, en que se atiende sin costo la misma falla. |
| **KPI** | Indicador clave: un número que mide cómo va algo (ventas, margen, rendimiento…). |
| **Lote** | Grupo de unidades fabricadas en una orden de producción, que pasa por control de calidad. |
| **Margen** | Lo que queda del precio después de restar el costo. |
| **Mínimo / máximo** | Existencia mínima (en ella o por debajo, el producto está *crítico*) y máxima (hasta donde sugiere comprar el reabastecimiento). |
| **Movimiento** | Cada entrada, salida o ajuste de inventario, con su documento de origen. |
| **OPI** | Orden de servicio técnico (instalación, mantenimiento, reparación). |
| **Pipeline** | Vista de cotizaciones en columnas por estado, con tarjetas que se pueden arrastrar. |
| **Portal de clientes** | Área privada del sitio web para los clientes con cuenta. |
| **Precio de referencia** | Precio publicado en el sitio; la cotización confirma el precio final. |
| **Proveedor preferente** | Proveedor principal de un producto; el reabastecimiento agrupa las sugerencias por él. |
| **Reabastecimiento** | Lista calculada por el sistema de lo que conviene comprar. |
| **Recepción** | Registro de la mercadería que llegó de una compra; suma existencias y recalcula el costo. |
| **Rendimiento (yield)** | De lo planificado en producción, qué porcentaje salió bueno y entró al inventario. |
| **Retrabajo** | Corregir unidades no conformes para volver a inspeccionarlas. |
| **Rol** | Puesto de trabajo en el sistema; decide qué módulos se ven y qué se puede hacer. |
| **Rotación** | Qué tan rápido se usa un producto: alta, media, baja o sin movimiento. |
| **RUC** | Registro Único de Contribuyente: número fiscal de una empresa en Nicaragua. |
| **Ruta de producción** | Los pasos ordenados para fabricar un producto. |
| **Saldo** | Lo que falta por pagar de una factura. |
| **Scrap** | Unidades desechadas en control de calidad; no entran al inventario. |
| **SKU** | Código único de cada producto. |
| **Stock crítico** | Producto con existencia igual o menor a su mínimo. |
| **Sucursal principal** | Ubicación del punto de venta, de donde sale lo que se vende. |
| **Ticket promedio** | Lo que se vende en promedio por factura. |
| **Tiempo de ciclo** | Tiempo promedio desde que se inicia una orden de producción hasta que se termina. |
| **Tipo de cambio** | Córdobas por dólar, para convertir el costo de las compras en dólares. |
| **Traslado** | Movimiento de mercadería entre la bodega y la sucursal; no cambia el total. |
| **Vencida** | Factura de crédito o cotización que pasó su fecha límite. |
| **Vuelto** | Lo que se le devuelve al cliente cuando paga en efectivo con más del total. |
